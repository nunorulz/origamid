Talvez você já tenha ouvido falar sobre o Vue Resources, anteriormente esse era o pacote recomendado por padrão para fazer requisições HTTP em aplicações Vue.

Porém em novembro de 2016, o Evan You, criador do Vue, anunciou que eles estavam removendo o pacote do status de recomendação padrão.

A partir daí o pacote mais indicado para solucionar esse problema passou o ser o "axios", que também possui uma ótima integração com o Vue e ainda trabalha de forma isomórfica: pode ser usado tanto no client (browser) quanto no server (Server Side Rendering).

Para ver mais detalhes sobre o anúncio oficial, acesse: https://medium.com/the-vue-point/retiring-vue-resource-871a82880af4
