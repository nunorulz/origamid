Alguns pacotes npm que foram adicionados ao package.json na criação do projeto possuem novas versões, essas versões geralmente trazem algumas melhorias e correções de bugs.

Para atualizar rode os comandos abaixo:

Dependências:

npm i vue@^2

Dependêncidas de desenvolvimento:

npm i -D @vue/cli-plugin-babel@^3 @vue/cli-plugin-eslint@^3 @vue/cli-service@^3 eslint@^5 eslint-plugin-vue@^5 vue-template-compiler@^2
