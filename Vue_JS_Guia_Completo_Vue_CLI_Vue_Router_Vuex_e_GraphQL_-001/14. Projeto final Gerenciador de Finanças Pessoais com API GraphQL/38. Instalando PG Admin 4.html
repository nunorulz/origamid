Na próxima aula iremos acessar nosso banco de dados PostgreSQL usando uma interface gráfica.

Para isso iremos utilizar o Pg Admin 4, portanto preciso que você instale configure ele na sua máquina.

Esta é a página de download oficial: https://www.pgadmin.org/download/

No Windows e MacOS a instalação pode ser feita por meio dos executáveis.

No Linux via terminal, segue dois artigos para auxílio:

https://www.journaldev.com/26285/install-postgresql-pgadmin4-ubuntu

https://linuxhint.com/install-pgadmin4-ubuntu/

Obs: não é necessário instalar o PostgreSQL em si, apenas o PG Admin pois ele já está instalado por meio do Docker.
